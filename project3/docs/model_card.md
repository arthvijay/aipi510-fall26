# Model card

RideCast is a chronological supervised regression model for systemwide hourly
rentals. It compares a mean baseline with two small random forests and selects
the lower validation-MAE forest. Metrics are generated by `run-pipeline`; no
values are claimed until a real dataset run writes `reports/metrics.json`.

The model is intended for conditional historical scenario exploration. Weather
is supplied by the user, and scenario differences are not causal effects.
Reliability can vary by hour, weather, rare conditions, and missing periods.
It must not be interpreted as station-level placement or a capacity guarantee.
